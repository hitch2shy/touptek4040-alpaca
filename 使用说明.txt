ToupTek 4040 ASCOM Alpaca 相机控制软件——正式版使用说明
========================================================

一、适用范围
------------
系统：64 位 Windows 10/11。
相机：sMAX16AM-U3-CL-GPS，4096 × 4096，序列号
TP241025143218C92B01151AEC40CB7。必须使用稳定的 USB 3.x（设备路径应为
SuperSpeed/SS），先安装 ToupTek 官方驱动。真实相机连接失败时绝不自动
切换模拟器。

解压 ToupTek4040Control.zip 后运行，不要在压缩包内直接启动。目录包含
ToupTek4040Alpaca.exe、ToupTek4040GUI.exe、64 位 toupcam.dll、
touptek4040.json、使用说明.txt、BUILD-INFO.txt 和 _runtime。不要删除或
改名。正式包不使用 touptek4040.ini；只有通过 --config 明确选择旧 INI
时才兼容读取。

二、配置文件
------------
默认读取 EXE 同目录的 touptek4040.json。JSON 为 UTF-8，拒绝重复、未知
字段及错误数据类型。

server.host=0.0.0.0，server.port=11111，server.discovery_port=32227。
camera.source=toupcam（真实相机）或显式 sim（模拟器）；
camera.serial 为上述批准序列号；camera.readout_mode=RAW 12-bit；
camera.gain=null 表示连接时保留设备值。

owner 默认值：
startup_timeout_s=10、connect_timeout_s=20、command_timeout_s=5、
exposure_overhead_s=10、exposure_multiplier=1.02、
structural_reopen_settle_s=0.5、abort_timeout_s=2、
disconnect_timeout_s=10。曝光固定余量的当前最小允许值为 0.252 秒。
logging.level=INFO，logging.directory=logs；web.enabled=true；
security.trusted_lan_only=true。

三、进程隔离与故障恢复
----------------------
真实 SDK 只在受监督的 owner 子进程内加载；主服务不加载 SDK。Open、设置、
Trigger、Abort、Close 或图像传输超时/崩溃时，只终止该代 owner；失败曝光
不重试、不发布图像，共享内存会清理。替代 owner 保持断开，必须明确再次
Connect。模拟器始终在主进程中运行，不启动 owner。日志位于 logs；
故障报告请附 BUILD-INFO、日志、配置、时间和操作步骤。

四、网页控制台和防露加热
------------------------
启动 ToupTek4040Alpaca.exe，在浏览器打开
http://127.0.0.1:11111/ui/。可 Connect、设置 ROI/Bin/RAW/增益/制冷、
单次曝光或预览，并下载 FITS。网页还提供防露加热 Off 和设备报告的
1..HEAT_MAX 整数档位；它是 Web 专用能力，不属于 Alpaca Camera V4，
SupportedActions/Action 中没有加热扩展。N.I.N.A. 连接期间仍可从网页调节。

曝光期间禁止写加热档位，但状态读取返回最后一次设备确认的缓存值。正常
Disconnect 或程序关闭会精确恢复本次 Connect 时捕获的 HEAT 档位。若
owner 故障导致连接丢失，重新 Connect 后再操作。加热与 TEC 制冷、目标
温度和风扇彼此独立。

五、图像和 Camera V4
--------------------
RAW 12-bit 使用 uint16 容器、有效范围 0..4095；RAW 8-bit 为 0..255。
传感器边界为 4096 × 4096。支持 Bin 1..8；设备不原生支持的组合使用软件
回退（例如 Bin 3 得到 1365）。结构变更会安全重开相机。暗场/偏置零曝光
按硬件最短值处理；亮场曝光必须大于零。

Alpaca 支持标准 JSON ImageArray、二进制 ImageBytes；网页提供 PNG 预览、
FITS 下载和 JSON 状态。Camera API V12 的 PUT 参数大小写严格遵循规范，
例如 Connected、Duration、Light、BinX、BinY、StartX、StartY、NumX、
NumY、Gain、SetCCDTemperature、CoolerOn。

六、N.I.N.A.、发现和安全
------------------------
先启动 Alpaca 服务。在 N.I.N.A. 选择 ASCOM Alpaca Camera，主机
127.0.0.1、端口 11111、设备 0。远程可信局域网可使用电脑局域网地址。
Windows 防火墙需仅对可信网络允许 TCP 11111 和 UDP 32227。软件没有公网
认证与 TLS，不得端口转发或暴露到互联网。一个真实相机只能由一个 owner
占用；不要同时运行 GUI、另一个服务或 ToupView。

建议连接顺序：启动服务→网页短曝光确认→网页保持服务运行→N.I.N.A.
连接。主控连接时网页加热仍可用。Alpaca PUT 表单键必须使用 API V12
规定大小写。

七、本地 GUI
------------
关闭占用相机的软件后运行 ToupTek4040GUI.exe，Connect 后可设置 RAW、
Gain、Bin、ROI、曝光和制冷。Start preview/Stop preview 控制采集；实际
像素浏览优先使用网页控制台。结束时 Disconnect。

八、排障
--------
枚举为 USB2.0、RHUB.HS 或掉线：更换支持 SuperSpeed 的线缆，直连后置
SS/SS10 接口，断电十秒重连。端口占用：关闭重复服务或修改 JSON。
相机忙：关闭 ToupView、GUI、N.I.N.A. 的旧连接。owner 超时后：确认硬件
恢复，再明确 Connect；不要假定替代 owner 自动连接。网页打不开：检查
服务窗口、web.enabled、防火墙和端口。图像异常：先用 RAW12、Bin1、
32 × 32 或 512 × 512、小于 1 秒曝光验证，再逐步扩大。
